## Limits and decision integrity

**G1-J2 pilot feasibility PASS** for reproducible Git provenance, true builder/consumer OS separation, physical CSM equivalence and public PlanAsync. No claim of statistical or CPU throughput improvement: short batches and a single shared hosted runner offer no stable CPU Amdahl attribution. Raw allocations/CPU/wall are archived to document harness mechanics only, **not** as G1-J product decision samples.

The builder's `PlanAsync` oracle uses the public API itself, supported by independent arithmetic checks; a separate implementation of an exact reconciliation reference is not part of this pilot. The text corpus is small, has no reused chunks and is **not** a representative .NET DLL/EXE pair. No idle pool trim tests, malformed CSM stress, multiple hosted CPU runs, Windows/AOT decision matrix, or preregistered numerical budgets have yet been completed.

Next required research: pin verifiable real .NET *binary* version pairs, including mixed reuse and multi-CBLK strata; implement independent reuse accounting; calibrate CPU run length/noise and idle memory/GC on independent GitHub-hosted runners; freeze numerical budgets in a separate reviewed protocol update before any decision runs. The top-level experiment remains `RUNNING / NO_VERDICT_EXPLORATORY`, with production source and defaults unchanged.
