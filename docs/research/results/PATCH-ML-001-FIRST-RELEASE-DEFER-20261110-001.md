# PATCH-ML-001 — first-release DEFER of learned dictionary-reference ranking

**EvidenceId:** `PATCH-ML-001/FIRST-RELEASE-DEFER-20261110-001`. **ExperimentId:** `PATCH-ML-001`. Date: 2026-11-10. Owner [#223](https://github.com/definitely-stable/ChunkShift/issues/223); release research gate [#251](https://github.com/definitely-stable/ChunkShift/issues/251).

**First-release disposition: `DEFER / NO_PRODUCTION_ADOPT`.** Do not add a learned candidate selector, training/inference subsystem, new BuildPolicy, public API, CSP/CSM representation or apply-side model. Preserve production deterministic dictionary selection and D15. This is an **entry-gate decision**, *not an ML model trial, ML model benchmark, holdout comparison, or universal REJECT of learning-based search*.

## Decision question and prerequisites

#223 asks whether a learned ranker can either (A) improve final physical patch size by >=10% against the best non-ML selector, or (B) remain within +1% patch bytes while reducing expensive candidate trials >=2x and materially improving Create CPU/wall on fresh confirmation. Both outcomes require matched source/candidate budgets, an honest non-ML baseline, deterministic result selection and independent product-family confirmation. The prerequisites in #181 (PATCH-ENC-005) and #183 (PATCH-GAP-001 G2) have already been completed; their negative results do **not** implicitly count as a learned-model test.

The first-release necessary gate is whether an **independently demonstrated richer candidate/representation universe** or an **already observed, repeatable candidate-cost opportunity** justifies training/inference and expenditure on an unopened model-confirmation holdout. Current evidence does not meet that gate. The right disposition is DEFER; not create a model to manufacture an experiment.

## Retained, re-verifiable primary evidence

1. **Exact whole-base, single-contiguous-dictionary G2 oracle (#181).** In an original prelocked calibration sample of 256 target entries across 4 version-pairs and 2 correlated product families, 10,311 base candidate starts were enumerated. Frozen H0 single-entry encoded costs total **974,223 B**, and the actual exhaustive whole-base oracle total **974,049 B**: **174 B (0.01786%)** headroom, **11/256** improved entries, **0/4** pairs passing the prespecified 3% threshold. The G2 5% aggregate promotion gate failed. G2 uses physical *entry cost* (stored zstd frame and 32 B per dictionary reference), **not the complete-CSP physical bytes**; do not promote this ratio as a whole-patch saving. Exact source: [G2 report](PATCH-ENC-005-G2-EVIDENCE-20261003-001.md) and [per-entry oracle JSON](data/PATCH-ENC-005-G2-EVIDENCE-20261003-001/oracle.json) / [verdict JSON](data/PATCH-ENC-005-G2-EVIDENCE-20261003-001/verdict.json). Original [GitHub-hosted G2 run](https://github.com/definitely-stable/ChunkShift/actions/runs/37150436770); frozen sample SHA `54061f4efe0969af0d772ddbc6d026fdf58bd4f2776514a9fb098753d062001d`. This constrains only **better start selection inside the original K4 contiguous dictionary representation**, not variable-K, sparse-run, full-file matching or a new codec.

2. **Predeclared H6-O false-negative guard (#181).** On 844 fixed-evaluation file pairs, real physical CSP H0 = **26,363,364 B** and `H6-O12-SF3-S128` = **30,248,709 B**, a **3,885,345 B (+14.7377%)** increase. Five paired wall ratios yield median **0.423377806× H0** and all 844/844 target reconstructions and same-build accepted/correctness CSP-SHA checks pass; peak over idle stayed below the frozen 160 MiB limit. Even with observed Create speed, the mandatory **<=0.97× H0 physical-byte guard was missed**. The H6 selector is a **non-ML** research comparator, not a trained scorer. Its result cannot be repackaged as measured ML trial reduction. Sources: [H6-O report](PATCH-ENC-005-H6O-EVIDENCE-20261004-001.md), [compact](data/PATCH-ENC-005-H6O-EVIDENCE-20261004-001/compact.json), [verdict](data/PATCH-ENC-005-H6O-EVIDENCE-20261004-001/verdict.json), [original hosted run](https://github.com/definitely-stable/ChunkShift/actions/runs/37187615407). Phase B H5-F/H6-P/H8 was STOPPED; D15 remains unchanged.

3. **Richer-source tests do not currently authorize an ML selector.** In #222's original but **already-opened two-file calibration**, exhaustive contiguous variable-K 1..4 reduced physical CSP **11,086 → 10,568 B (4.67%)** with **0 B additional gain from bounded disjoint composite runs**; seven of nine PAYL entries improved from fewer references. This is deterministic **representation/reference-count selection**, *not* oracle headroom for learning an improved ranking within equal K/search budget, and no Create CPU/RSS finalist evidence was collected. Sources: [PATCH-DICT-001 closeout](PATCH-DICT-001-D1B0B-FIRST-RELEASE-DEFER-20261109-001.md), [retained machine ledger](../../../benchmarks/experiments/patch-dict-001-d1b0b-first-release-closeout-20261109.json). D3P1 CLR token normalization (#221) and generic G1/G3/G4 (in #183) did not yield a qualified new CSP representation. The real HDiffPatch external whole-file reference shows substantial potential **in a different family of matching algorithms**; it is not a CSP-compatible dictionary-candidate scoring bound or independent ML result (see [#183 final closeout](PATCH-GAP-001-FIRST-RELEASE-CLOSEOUT-20261104-001.md)).

## Explicit scope of the decision

- **No model was trained**, no weights exist, no model inference was profiled, no baseline/ML candidate-ranking A/B was performed, and **no independent new ML confirmation or untouched holdout was opened**. Thus neither #223 adoption alternative (>=10% bytes or >=2× fewer codec trials with <=1% byte regression and meaningful Create speed) can be certified **PASS or FAIL**.
- Do **not** infer that the exact G2 174-byte oracle is an upper bound for trained models operating over an enlarged representation space, or that H6-O's faster build establishes model-based trial savings.
- Both in-app ML and ANN are deferred for the first public Patching release; the decoder must never depend on model inference or learned state. Keep the existing CSP v1 wire, library API, default deterministic H0 choice and frozen #181 STOP unchanged.
- Do not back-fit the **already viewed** G2, H6-O, D1-B0B, D3P1 or HDiffPatch evaluation rows into a newly advertised *fresh* ML holdout. Any future ML trial requires source-family separation, leak-check of version pairs/content hashes, immutable model/feature/weight digests and cross-platform deterministic selection.
- This is a release *evidence sufficiency* decision. It leaves room for future work once a **new, independently locked source/representation universe** yields (i) measurable oracle headroom vs the best *same-budget* non-ML scorer **or** (ii) independently measured high CPU/trial costs with matched output quality that simpler deterministic ranking fails to recover. Prior to training, preregister a bounded oracle, cheap non-ML ranker and two distinct adoption gates; do not reuse unqualified thresholds as retrospective proof.
- Close #223 as **first-release research accounted for** only after the source-bound closeout + verifier are merged and exact-head CI passes. Mark the corresponding #251 checklist item complete; leave #251 open for #224/#225 and the final persisted-architecture synthesis. No production CSP revision, publication, or PublicAPI freeze follows from this closeout.
