The experiment consumed original Microsoft.CodeAnalysis.CSharp 4.13.0 and 4.14.0 DLLs from official NuGet packages, subject to the package SHA-256 and original DLL SHA-256 *literal locks preregistered* in docs/benchmarks/PATCH-META-001-G1B1-PROTOCOL.md. **Do not treat builder-time dominance as 99% potentially cacheable work.** The opaque builder stage includes mandatory chunk verification, I/O, zstd encoding, candidate search and physical CSP output; its essential vs derived computational shares are not yet isolated. If entirely removed (an invalid counterfactual), it would save only approximately 0.26%-0.30% of observed wall on this pair, nowhere near the 30% issue gate.
